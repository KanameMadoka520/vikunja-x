# 阿罗娜会话历史管理

会话列表采用统一的「⋯」菜单，支持置顶/取消置顶、重命名、归档/恢复、确认后删除。当前会话的菜单另含导出与压缩上下文。桌面宽屏默认展示历史，手机和悬浮窗口使用可关闭的侧栏。新建会话先进入空白输入页，发送首条消息或上传附件时才建立服务器记录。

## 数据与运行语义

- `pinned`、`archived` 与会话一起加密持久化，旧记录默认 false；无需数据库迁移。
- 固定按置顶优先、最后消息活动时间倒序排序，并以 ID 打破同时间平局。整理操作不改变活动时间。
- 归档会取消置顶；置顶已归档会话会恢复它。不接受同时设置两者为 true。
- 标题、归档、置顶可在运行期间修改，在同一把锁下更新运行中的记录，避免 worker 完成时覆盖整理结果。权限始终限定为当前登录账户。
- 归档不停止模型请求、不改变上下文或项目权限。运行中或压缩中删除返回 409，界面提示先停止。
- 删除需确认具体会话，删除记录及不再被其他会话引用的对话附件；已执行的项目/任务操作不会撤销，其他分支及共享附件保留。
- 分支复制原消息，但不继承置顶、归档状态。

## API 与搜索

`POST /api/v2/ai/conversations/{id}/organization` 接受可选 title、pinned、archived。原 title 路由保持兼容。

列表新增 scope=active/archived/all，默认 all 保持旧客户端兼容；界面正常浏览使用 active，归档管理使用 archived，正常列表有搜索词时使用 all。搜索大小写不敏感，匹配标题、用户消息、最终回复，不搜索隐藏模型状态或工具诊断。服务端先过滤和排序，再分页；搜索词或范围改变回到第一页，删除末页最后一条自动回退。

前端只使用生成的 v2 客户端和 query 层。菜单使用浏览器顶层 popover，避免手机侧栏 overflow 裁切；支持方向键、Home/End、Escape，模态确认使用站点现有的原生 dialog 组件。取消删除、修改其他会话均不清空当前草稿。

## 设计参考

- [ChatGPT：Projects and chats](https://learn.chatgpt.com/docs/projects)：常用会话置顶、标题命名、搜索与归档分工。
- [ChatGPT：Deleting and archiving chats](https://help.openai.com/en/articles/8809935-deleting-and-archiving-chats-in-chatgpt)：列表更多操作、删除确认、归档可恢复。

参考公开交互原则，没有复制 ChatGPT 私有前端代码。阿罗娜具有后台修改项目的能力，因此额外明确归档、停止、删除的区别。
